# Fundamentos de Linux

Para iniciar en los fundamentos básicos de Linux y ejecutar los comandos para practicar lo que hice fue instalar Ubuntu en una Máquina virtual para así ejecutar comandos de forma sencilla.

## Comandos

Algunos comandos básicos para la navegación, búsqueda de directorios etc.. que voy a necesitar son:

**whoami:** este comando me muestra en la consola que usuario soy yo ahora mismo, por ejemplo en caso de que tenga varios usuarios dentro de mi sistema operativo y solo con algunos tenga diferentes permisos, este comando me ayuda a ver desde cual usuario estoy actualmente.
